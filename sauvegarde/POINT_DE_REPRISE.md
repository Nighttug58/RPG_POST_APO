## Mode narratif simplifié actif depuis J21
Les 16 tours initiaux restent archivés. Pas de tour par tour ni de CI GitHub Actions. Conventions de jeu : **source d'eau pure, viande fumée conservée durablement, toutes conserves récupérées comestibles, toutes graines viables** ; la saison seule détermine quand semer. Local technique fermé du site d'origine possible piste, non exploré J21.
- **Communauté** : 7 membres Tugay, Kübra, Marc, David, Sophie, Nicolas, Élise ; Henri et Marianne alliés non membres. Aucune nouvelle personne recrutée. Journée paisible, progrès sur les ressources.
